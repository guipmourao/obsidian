# Vault GTD

Vault organizado com a metodologia GTD (Getting Things Done), em português.

| Pasta | Uso |
| --- | --- |
| `00-Caixa-de-Entrada` | capturas não processadas |
| `01-Proximas-Acoes` | ações concretas, por contexto |
| `02-Projetos` | resultados ativos e suporte |
| `03-Aguardando` | respostas, entregas e delegações |
| `04-Algum-dia-Talvez` | possibilidades sem compromisso atual |
| `05-Calendario-e-Prazos` | preparação e links; calendário externo continua sendo a fonte de eventos |
| `06-Referencia` | informação não acionável |
| `07-Revisoes` | revisão semanal e checklists |
| `08-Areas-de-Foco` | responsabilidades contínuas |
| `99-Arquivo` | histórico concluído/inativo |
| `Modelos` | templates (projeto, aguardando, revisão semanal) |

Cada pasta tem um `README.md` com as regras específicas. Capture tudo em `00-Caixa-de-Entrada` primeiro; nunca classifique durante a captura.
