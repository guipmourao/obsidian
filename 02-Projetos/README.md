# Projetos

Um projeto é um resultado concluível que exige mais de uma ação.

- Nomeie como resultado: `Contrato assinado com fornecedor X`, não `Fornecedor X`.
- Todo projeto ativo precisa de uma próxima ação física e visível, ou um item correspondente em `03-Aguardando`.
- Use o modelo em `Modelos/Modelo-de-Projeto.md` para criar um novo projeto.
