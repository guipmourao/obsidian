# Calendário e Prazos

Esta pasta é paisagem rígida: compromissos, ações em dia/hora específicos e informação de dia específico. Não crie prazos artificiais.

O calendário externo (Google Calendar, etc.) continua sendo a fonte de eventos e alertas. Notas aqui servem para preparação e links, nunca para substituir notificações — o Obsidian não avisa ninguém.
