# Próximas Ações

Ações concretas, organizadas por contexto — a condição necessária para agir (computador, telefone, casa, rua, conversa), não prioridade.

Toda ação começa com verbo: `Ligar para Ana e confirmar o escopo`, não `Ana` ou `Projeto site`.

Comece com os contextos já criados aqui (`@computador`, `@telefone`, `@casa`, `@rua`, `@conversas`, `@baixa-energia`). Só crie um contexto novo quando ele realmente melhorar a decisão de qual ação fazer agora.
